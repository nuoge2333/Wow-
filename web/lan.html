好友无需公网 IP。让对方在 PCL / HMCL / BakaXL / FCL 启动器中选择「加入陶瓦房间」， 输入上面的房间号即可加入你的 Minecraft 服务端。
使用前提：开房前请先启动 Minecraft 服务端（「仪表盘 → 启动服务器」或 wow server start）。 陶瓦会自动扫描本机服务端端口并建立内网穿透。首次开房会联网从 Gitee 镜像下载陶瓦二进制（约 8–14 MB）， 之后复用本地缓存。可在 core/wow.yaml 的 lan 段配置 auto_room（服务器启动自动开房）、 mirror、version 等。
