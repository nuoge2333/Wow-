# 🌐 Web 面板使用说明

Wow~ 内置一个基于 Express + Socket.IO 的 Web 管理面板，可在浏览器里查看服务器状态、实时日志，并管理配置、模组、方案、主题等。

> Web 面板把前端操作转换成 CLI 命令执行，等价于在终端里使用 `wow` 命令。

---

## 一、启动与停止

```bash
# 启动（默认端口 8080，仅监听本机 127.0.0.1）
wow web start

# 指定端口 / 绑定地址
wow web start --port 9000 --host 0.0.0.0

# 查看运行状态
wow web status

# 停止
wow web stop
```

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `-p, --port <port>` | 监听端口 | `8080` |
| `--host <host>` | 绑定地址 | `127.0.0.1` |

- 当 `--host` 为 `127.0.0.1` 或 `localhost` 时，启动后会**自动打开浏览器**。
- 默认只监听本机；如需局域网/公网访问，使用 `--host 0.0.0.0`（请注意由此带来的安全风险，建议配合反向代理与 HTTPS）。

---

## 二、登录与认证

面板采用 **邮箱 + 验证码** 的登录方式（无密码）：

1. 在登录页输入邮箱，点击「获取验证码」。
2. 系统生成 6 位验证码，有效期 **5 分钟**：
   - 若已在 `wow.yaml` 配置 SMTP，验证码通过邮件发送；
   - 若未配置 SMTP，验证码会打印在**启动面板的终端控制台**（开发模式），并随登录接口一并返回 `devCode` 字段。
3. 输入验证码完成登录，后端签发 **JWT** 令牌，后续请求通过 `Authorization: Bearer <token>` 携带。

相关配置项（见 [配置参考](docs/CONFIG.md)）：

| 配置键 | 说明 | 默认值 |
|--------|------|--------|
| `web.auth_token` | JWT 签名密钥，首次启动时自动生成并持久化 | 自动生成 |
| `web.session_timeout` | 登录会话有效期（秒） | `86400`（24 小时） |
| `web.port` | 监听端口 | `8080` |
| `web.host` | 绑定地址 | `127.0.0.1` |
| `web.theme` | 面板主题包名 | `default` |

## 三、面板功能

| 功能 | 说明 |
|------|------|
| 服务器状态 | 显示运行中 / PID / 核心文件 / 服务器目录 |
| 实时日志 | 通过 WebSocket 每 500ms 推送 `logs/latest.log` 增量 |
| 配置管理 | 查看 / 修改 `wow.yaml` 与 `server.properties` |
| 模组列表 | 列出当前方案已安装模组 |
| 方案管理 | 列出方案及当前激活方案 |
| 主题切换 | 列出并切换主题包 |
| 命令执行 | 直接在面板里执行 `wow` CLI 命令 |

面板页面（静态资源）来自 `web/` 目录，首次启动时会从当前主题包（`themes/<web.theme>/`）复制生成；若主题包缺失，会生成最小默认页并提示安装主题。

---

## 四、接口与实时通信

- 数据接口以 `/api/` 开头，除认证接口外均需携带 JWT（详见 [Web API 参考](docs/API.md)）。
- 实时日志与命令结果通过 **Socket.IO** 推送，事件包括 `message`、`log`、`command`、`command_result`。

---

## 五、常见问题

- **打开面板是空白页 / 提示未找到主题包**：运行 `wow theme install <主题包.zip>` 安装主题，或确认 `themes/default` 存在。
- **验证码没收到邮件**：多半是 SMTP 未配置，请看启动面板的终端控制台输出（开发模式会打印 `devCode`）。
- **想换端口 / 允许远程访问**：用 `wow web start --port <端口> --host 0.0.0.0`。
