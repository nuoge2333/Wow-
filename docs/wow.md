# 彩蛋：为什么叫 **Wow～**？

> *“OH WOW, OH WOW, OH WOW!”*  
> —— 史蒂夫·乔布斯（Steve Jobs）最后的感叹

---

当时我想给这个启动器取名时，思考了很久。

Minecraft 社区已有许多优秀工具：  
- **Fabric** —— 突出轻量，可编织的生态；  
- **PCL**（Plain Craft Launcher）—— 强调简洁易用；  
- **FCL**（Fold Craft Launcher）—— 聚焦移动端体验。  

但它们大多用单词或缩写命名，都有一个共性：**抽象**

**作为你，第一次听到这些名字，难免懵懵懂懂。**

对英语非母语、尤其是刚接触编程或服务器概念的新手而言，“Fabric”是什么？“PCL”又代表什么？第一次听到，恐怕只能茫然地重复：“**啊？这是啥？**”

又得钻进B站里面一通找

而Wow~所针对的，恰恰是这群人——
他们可能刚攒够钱买了台能跑 Minecraft 的电脑，结果发现还要再花一笔钱去买面板
他们可能连 Java 是什么都不知道，
他们只是想和朋友开个服，想摆脱网易的土豆服务器……


于是我想：能不能用一个**全世界人人都能看懂、张口就能念出来**的词？

“**Wow～**” 就是答案。  
只要认识英文字母，看到它，你一定会脱口而出：**“哇！”**

我不希望选择高大上的名字，也不追求极客范儿的缩写，
但我回想起乔布斯的临终遗言，豁然开朗，就选择了一个**最朴素**的*拟声词*：**Wow～**

这正是我希望小白们在使用本工具时的感受——  
> **“Wow～ 原来开服这么简单！”**

---

我知道，市面上已有不少服务器管理面板或一键脚本。

我知道，各个视频平台有关于开服的教程

但看看这又看看那，要么就是用着不顺手，要么就是要翻一大坨文档，要么就是要你的钱包又变瘪，真正好用的可能不多

更糟的是，很多教程假设你**“已经会用命令行”“已经装好 Java”“已经知道什么是端口转发”**……

（虽然命令式的菜单也不是非常顺手…）

可现实是：**大多数玩家只想快乐联机，不想成为运维工程师。**

Wow～ 就是要打破这一切。
它不是一个“专业工具”，而是一个**惊喜**

而 **Wow～** 的使命，就是：  
- 让你**无需折腾 Java 环境**  
- **一键启动**，无论放 U 盘还是移动硬盘，或者在普通人常用的**Windows**，和社区中推荐的**Linux**，甚至现在可能在你手上的手机（理论上可行）
- **零配置上手**，省去找资源、配依赖的时间。

---

虽然今年的汕头失去了应有的烟火，也没有北方新年会出现的雪，并且意外多了新年不应有的大热天，但写到这里，我希望Wow~能够：

让每一个刚攒够硬件的小白，都能**随时随地、轻松开服**。  
那一刻的惊喜与成就感，就是 “Wow～” 的全部意义。

> **Wow～ 不只是一个名字，  
> 更是一句惊叹，一种成就感**

如果你用Wow~成功开启了你人生中的第一台服务器，请你对着屏幕说一句：

>**Wow~ 老己，你做到了！**
