# 🖥️ M 模式 TUI 使用说明

> `wow m` 的常驻界面：一次进入，六页排布。字母键按下即切页，数字输入后回车执行。

---

## 一、进入与退出

```bash
wow m            # 进入 M 模式 TUI
WOW_NO_TUI=1 wow m   # 强制走兼容模式（逐行读，无整屏重绘）
```

- 非 TTY 环境（管道、`cron`、重定向）会自动降级到兼容模式，功能一致；
- 界面内按 `0` 回车（或 Ctrl+C）触发退出确认，按 `Y` 才真退出；
  独立入口（`wow` / `wow m`）退回命令行，从开服控制台 `:wow` 进来的菜单
  只退出菜单、回到 `:wow` 控制台——**不会**把正在跑的服务器一起关掉；
- 任何功能执行完会提示「按回车键返回...」，回车回到原页；
- **菜单期间不显示服务器日志**：从第一帧到退出，MC 的 stdout/stderr 回显与
  L 模式的日志跟踪都被闸门挡在门外（见第六节）。日志照常写 `wow-stdout.log`，
  要看就用 `:mc`（回开服控制台）、`:wowlog`（最近 10 条 wow 指令日志）或
  菜单 `Q` 页第 5 项「查看控制台日志（实时跟踪）」；
- 退出确认里 `y` / `Y` 都算确认（CapsLock 下敲大写不会再跳到 `Y` 页）。

## 二、界面结构

```

  服务器: 🟢 运行中 (PID 12345)　　方案: 生存服
  已装 Java: Java 17, Java 21
  当前 Java: /usr/lib/jvm/java-17-openjdk-amd64/bin/java
══════════════════════════════════════════════════════════════════════

  ── 服务器启停 / 运行状态
   1. 启动 / 停止服务器         运行中
   2. 服务器状态监控            可看实时日志
   3. 查看服务端属性（全部）    server.properties
   4. 修改单个服务端属性        键值直改
   5. 服务端属性快速向导        端口/人数/难度
   6. 重置服务端属性为默认      单项回滚
   7. 错误日志分析（AI）        崩溃排查
   8. 查看控制台日志（实时跟踪） Ctrl+C 停
   9. 开房联机（陶瓦，同 R 页 1） 无需公网 IP

──────────────────────────────────────────────────────────────────────
  [Q]服务器 [W]方案 [E]内容 [R]网络 [T]工具 [Y]高级 [L]长命令  [0]退出
  输入编号后回车执行　Q/W/E/R/T/Y 切页　L 长命令　0 退出
```

正在输入编号时，提示行换成输入回显：

```
  编号: 3▏　回车执行 · Backspace 删除
```

> 界面宽度 **70 列**（`tui.WIDTH`）：恰好等于底部导航那一行的宽度，
> 框线与导航齐边；80 列终端不会换行。窗宽不足 70 时终端会自行折行，
> 建议至少 80 列。

| 区块 | 说明 |
|------|------|
| 状态栏（4 行 + 上下框线 = 6 个物理行） | 版本与当前页 / 服务器运行态与 PID 与当前方案 / 已装 Java / 当前 Java。取数 300ms 缓存，任一字段取数失败只降级成 `（未知）`，不影响整屏 |
| 标题行 | 当前页名称 |
| 功能项 | 编号（青色，本页顺号 1,2,3…）+ 名称（左对齐）+ 提示（灰色右置，部分项动态计算）。总宽超过 70 列时先截名称、再截提示，编号列永远完整 |
| 导航栏 | 当前页高亮反显，其余暗色；`L` 与 `0` 常驻 |
| 提示行 | 操作提示；执行结果或错误以黄色显示在末行 |

## 三、按键

| 按键 | 动作 |
|------|------|
| `Q` `W` `E` `R` `T` `Y` | 切换页面并重绘（按下即生效） |
| `1`~`9` 等 | 输入**本页序号**，**回车**执行（每页都从 1 开始） |
| `Backspace` | 删掉输错的最后一位 |
| `Enter` | 提交编号；编号为空时刷新当前页状态 |
| `L` | 进入长命令模式（清屏后回到熟悉的 REPL） |
| `0` + `Enter` | 退出确认 |
| `Ctrl+C` | 退出确认；在二级流程（如实时日志）中则是中断并返回 |

- 字母不区分大小写（统一 `.toUpperCase()`）；
- **数字要回车**：和原来的数字菜单一致——输入完整编号再回车，不猜、不等。
  编号最长 4 位，输入 4 位就停住；
- **每页都是 1,2,3,4,5…**：同一页里序号唯一，所以「敲几」永远指本页第几项。
  换页不改习惯，也不用记「哪个功能在哪个编号」；
- **只认本页序号**（V3.7.4 起）：每个编号只在本页有意义，不跨页、不认旧编号。
  敲本页没有的号，底部提示「没有编号 xxx 的功能（本页 1~n…）」；
- **菜单只有一层**：任何一项进去都是直接执行，不会再弹 `请选择 (0-N)` 的二级菜单。

## 四、六页排布

**菜单只有一层**（V3.7.4 扁平化）：每个编号就是最终动作，点进去不会再有
`请选择 (0-N)` 的选择页。原来「方案管理 / 系统设置 / 错误日志分析 /
联机(陶瓦) / 管理模组 / server.properties / 下载管理器 / 安装整合包 /
模组搜索下载 / Web 主题」这十个聚合入口已经拆成页内独立项。

> 旧编号兼容（界面上灰色的 `旧 22` 小注、跨页跳转）在 V3.7.4 一并移除：
> 现在编号只在本页有效，以前记的 `22` / `141` 请改用页内顺号。

## 五、长命令模式（`L`）

按 `L` 后清屏进入 REPL：

```
wow> 
```

- 敲完指令回车执行，输出后提示「按回车返回 M 模式...」；
- 回车后重新初始化界面并落回 **`Q` 页**；
- 从 `wow server start` 的控制台里按 `:wow` 进入 M 模式时，按 `L` 会回到
  原来的 `:wow` 控制台（而不是另起一个 REPL），并可在 `:mc` / `:wow` /
  `:lan` 之间切换——把三视图看成「L 模式里 Minecraft 正在运行时的形态」。

## 六、实现约束（给改代码的人看）

0. **画面独占**：TUI 从第一帧前置位 `tui.markScreenActive(true)`，`kb.close()`
   之后、任何 `leaving` 分支之前复位。`server.js` 的 MC 回显
   （`_mode === 'mc' && !tuiOwnsScreen()`）与 `cli.js` 的跟踪打印
   （`printLine` 里 `isScreenActive()` 直接 return）都要先问它。新增任何
   「会自己往终端写」的日志源时，也必须过这道闸；被挡住的只是回显，
   **落盘不能跟着挡**。

1. **全局只有一个键盘消费者**：`tui.js` 里 `createInterface` 只出现在
   TUI 态的 `mkRl()` 和临时提问的 `askLine()`；`interactive.js` 里零处。
2. **执行动作前必须交权**：`kb.suspend()` 依次做
   `rl.close()` → `removeListener('keypress')` → 排空 stdin → `setRawMode(false)`
   → 清屏 → `setImmediate` 让出一轮。顺序不能换：
   - 先卸监听再 close 会把触发键留在 readline 缓冲里，屏幕出现 `11`；
   - 不排空 stdin 会把连按的第二键喂给动作里的 `question`。
3. **临时提问用 `terminal: false`**：否则终端行模式回显 + readline 自身
   回显叠加，出现 `33`。
4. **不要把 `askLine` 绑到 `rl.on('close')`**：会提前 resolve 空串，
   导致「按回车键返回」卡住。
5. **加功能只改两处**：① 在 `PAGES` 对应页的 `items` 里加一项（`id` 写顺号，
   `label` + 可选 `hint`）；② 用 `action('页键', 顺号, fn)` 注册动作函数。
   `dispatchMenuItem` 按 `ACTION_BY_KEY`（页键:顺号）直接派发，**没有中间 switch**。
   `menu_flat.test.js` 会验证「每页 N 项 = N 个动作」，漏注册直接红。
   V3.7.4 起没有 `legacy` 字段，编号只在本页有效。
6. **Ctrl+C 只报一次**：`keypress` 的 ctrl-c 和 readline 的 `SIGINT` 会各触发
   一次，`fireInterrupt()` 用 80ms 时间窗去重。少了它，确认框刚画出来就
   `process.exit`——用户看到的是「按一下 Ctrl+C 程序直接没了」。
7. **半截编号不能带到下一页**：`cancelNumber()` 要在切页 / 进 L / 退出确认 /
   EOF 四处都调。否则敲了 `1` 再按 `W`，W 页会顶着一个「编号: 1」，
   回车就是在 W 页执行 `1`——用户以为切页把输入清了。
8. **要退出菜单≠要退出进程**：从开服控制台 `:wow` 进来时传 `returnOnExit`，
   退出只离开 TUI 循环，由 server 把画面还给 `:wow`。

## 七、兼容模式

`WOW_NO_TUI=1` 或非 TTY 时走 `runCompatMode`：打印整屏页面表，读一行输入
（数字 / 页键 / `L` / `0`）后回车执行。页面表、编号表、业务分支与 TUI 模式
共用同一份 `PAGES`、`resolveNumber()` 与 `dispatchMenuItem`，功能不会有差异——
「每页 1,2,3… 顺号、编号只在本页有效、一层直达」两边完全一致。
